# Historical GPL development builds

This repository preserves the corresponding source for historical GPL-3.0 development builds. Existing GPL grants remain in effect. The current EUB Changes for Web development build is maintained separately from this project and EUB Changes desktop.

Select the matching tag at https://github.com/emnyeca/changes-web/releases and download its changes-source.zip. The archive contains editable application and engine sources, build inputs, and pinned runtime metadata. The original RC2 source also remains at https://emnyeca.com/eub/changes/app/changes-source.zip.

The original stage.py documents the exact source revisions and how to stage the runtime. Use the included engine.zip for the corresponding editable Python files. See the archive's README and package-lock.json for build commands and dependency versions.
